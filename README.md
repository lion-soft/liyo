# LIYO

LIYO is a modern business management application built with React, Vite, and Supabase.

## Features

- Dashboard
- Customer Management
- Product & Inventory Management
- Orders
- Expenses
- Invoices
- Analytics
- LIYO AI
- Business Settings
- Secure Authentication
- Supabase Database

## Tech Stack

- React
- Vite
- Supabase
- React Router
- CSS
